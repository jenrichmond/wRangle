# Data Wrangling Tool

An interactive tool that helps psychology students clean messy survey
data in R, using the tidyverse (dplyr, tidyr, readr, lubridate), janitor,
naniar, and here packages.

Click through from raw import to an analysis-ready dataset, or jump straight
to whichever task matches what you're stuck on — importing, renaming,
checking variable types, handling missing data, dates, recoding, reshaping,
filtering by inclusion/exclusion criteria, combining files, or exporting a
clean file.

**Live tool:** enable GitHub Pages on this repo (Settings → Pages → Source:
`main` branch, `/ (root)`) and this README will link to it automatically at
`https://<your-username>.github.io/data-wrangling-tool/`.

Built by [Reveal Research](https://www.revealresearch.org) in collaboration
with Claude Cowork.

## Suggesting changes

Found something confusing, missing, or wrong? Open an
[issue](../../issues/new) describing it, or submit a pull request if you'd
like to fix it yourself — `index.html` is a single self-contained file, no
build step required.
